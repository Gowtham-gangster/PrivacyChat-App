Core Security Principles

Strictly 1-to-1

No group chats, no channels, no tracking cookies, and no algorithmic recommendation feeds.

Double Ratchet E2EE

Signal-protocol inspired ratchet with X25519, HKDF-SHA256, and AES-256-GCM message encryption.

Zero Plaintext Server

The backend stores only encrypted ciphertexts. Neither server admins nor ISPs can read your data.

Encrypted Calls & Media

Peer-to-peer WebRTC voice/video with DTLS-SRTP and AES-GCM client-encrypted media storage.

How to Verify and Install

  1. Download the APK above directly onto your Android device.
  2. Open your device's Settings → Security and allow Install unknown apps for your browser or file manager.
  3. (Recommended) Verify the APK's SHA-256 signature on your workstation:
    sha256sum privychat-release.apk
  4. Confirm the output hash matches the green SHA-256 string above.
  5. Tap the APK file in your notification bar or Downloads folder and select Install.
